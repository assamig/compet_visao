Na imagem escolhida, o limiar adaptativo foi o que funcionou melhor porque destacou os contornos com mais clareza e reduziu o ruído do fundo. A imagem das chaves foi a melhor escolha para esse processamento porque as formas irregulares e os espaços entre elas geram bordas bem definidas. Esse método funciona bem nesse caso porque combina a segmentação por limiar com filtros de suavização, deixando os objetos mais nítidos e fáceis de analisar.
